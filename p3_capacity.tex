\begin{abstract}
A low retrieval score can reflect the question and the rule used to select an answer, as well as a model's ability to associate names with values.
We measure recall as the number of associations increases in \NewNModels{} open models from 70M to 2.8B parameters, then compare questions using the same assignments.
At sixteen bindings, deleting \texttt{is} from the original question raises Pythia-410M recall from \NewFourTenOriginal{} to \NewFourTenColon{} without changing the weights or scoring rule.
In a preregistered comparison with the original question fixed, supervised hidden-state probes outperform trained candidate-logit decoders in all three held-out models.
Two of those models also meet the registered ten-point probe advantage over native output.
These results support testing the question and readout before treating poor recall as evidence that a larger model is needed.
\end{abstract}

\section{Introduction}\label{sec:intro}
A prompt lists \texttt{cache: rotate}, \texttt{token: verify}, and \texttt{socket: flush}, then asks \texttt{The task for token is:}.
To return \texttt{verify}, a language model must distinguish the value assigned to \texttt{token} from values assigned to the other names.
This is in-context binding: associating an entity with an attribute supplied by the current context \citep{binding2310}.
If the model returns \texttt{flush}, the error is easy to score but harder to interpret.
It may fail to retrieve the queried association, or a different query or readout may recover an answer that its current output misses.
Before rejecting a small model on this task, we need to know whether changing the question or readout improves its recall.

Small models are useful when inference cost or device memory limits the choice of model.
Longer pretraining can make a smaller model attractive for repeated use \citep{touvron2023}, and on-device models target settings where model size is constrained \citep{mobilellm2024}.
For example, filling a configuration field or a tool argument can require returning the value assigned to one name among several plausible alternatives.
Fitting the relevant text into a context window does not ensure that the model retrieves the right value.
We study that retrieval problem separately from the other requirements of an application.

Under the question above, Pythia-410M recalls \NewFourTenOriginal{} of queried values at sixteen bindings.
Deleting \texttt{is}, to ask \texttt{The task for token:}, raises recall to \NewFourTenColon{} on the same assignments and queried entities.
The model's weights and scoring rule are unchanged.
The original curve therefore cannot bound how many associations this model retrieves under other questions.
Because changing the question also changes the hidden states, this comparison alone does not locate the failure within the network.

To investigate the readout while holding the original question fixed, we compare three ways of predicting its answer.
The native output chooses the value with the highest model score.
A supervised decoder learns to combine all candidate-value scores, and a supervised hidden-state probe predicts the value from an intermediate activation vector.
The score decoder matters because a probe could beat the native choice even when the output scores retain useful information: the native decision rule may use those scores poorly.
Comparing the probe with a trained score decoder tests whether its advantage survives a learned output decision rule.
It does not identify a mechanism or establish that the model uses the probed information \citep{hewitt2019,belinkov2022}.

Copying and phone-book lookup studies show that transformers can retrieve associations from context \citep{jelassi2024}, while probing studies recover correct-answer information on trials where a model answers incorrectly \citep{orgad2024,karim2026}.
We extend our earlier comparison of trained state and candidate-logit decoders \citep{decodable2609} by varying load and query wording, then testing a preregistered comparison on additional models.
Holding the assignments fixed lets us measure query effects on the same retrieval problems.

Matched wording controls improve retrieval in five models, with additional exact-cue and worked-example tests showing that gains depend on both model and query (Section~\ref{sec:wording}).
Recall curves across \NewNModels{} models show how performance under the original question changes with load (Section~\ref{sec:capacity}).
At the registered layer and load, hidden-state probes exceed trained candidate-logit decoders in all three held-out models (Section~\ref{sec:hidden}).
Across pretraining checkpoints, probe results depend on which layer is tested (Section~\ref{sec:development}).
Capacity curves therefore need to specify the question and readout used to measure them.

\section{Measuring retrieval under a specified protocol}\label{sec:setup}
\paragraph{Task and scoring.}
Each trial lists $K$ assignments in the form \texttt{entity: value}, then queries one uniformly selected entity.
We call $K$ the load.
Entities are distinct within a prompt, while values are sampled uniformly with replacement from a tokenizer-specific pool $\mathcal V$ of 67 to 71 single-token words.
Using single-token values makes correctness an exact comparison at one output position, without an additional rule for matching generated strings.
Under the original question, \texttt{The task for $e_j$ is:}, we select the value with the highest next-token logit, the model's unnormalized score, among $\mathcal V$.
We call this the native output and measure recall as the fraction of trials where it equals the queried entity's value.
Tokens outside the pool do not compete, so the score measures restricted retrieval rather than free-form instruction following.

\paragraph{Load and distractors.}
The main grid uses $K\in\{1,2,3,4,6,8,10,12,16,20,24,32,40,48,64\}$.
For each load, six random seeds generate 96 trials each, giving 576 trials per condition.
Each seed fixes the assignments and queried entity; models sharing a tokenizer therefore receive the same prompts.
We compare no distractors ($D=0$) with a code-like block between the list and question (nominal $D=256$).
The block contains 32 assignment lines that mention neither the selected entities nor the value words.
It measures \RevFillerLo{} to \RevFillerHi{} tokens depending on the tokenizer, so its nominal name is not a token count.
This condition measures the combined effect of added text and greater separation from the question.

\paragraph{Models and execution.}
We evaluate GPT-2 at three sizes; OPT-125M, 350M and 1.3B; Pythia-70M, 160M, 410M, 1B, 1.4B and 2.8B; Qwen2.5-0.5B and 1.5B; SmolLM2-360M; and OLMo-2-1B \citep{zhang2022opt,biderman2023,qwen2024,smollm2025,olmo2024}.
All are base models.
Their weights remain frozen throughout evaluation; the separate probes and score decoders described below are trained on labeled examples.
The current results use float32 execution, TF32 disabled, dynamic left padding and mask-derived position IDs for GPT-2.
This configuration restores single-binding recall in four models excluded from the earlier measurement.
Precision, padding and position handling change together in this rerun, so we cannot attribute the improvement to any one of them (Appendix~\ref{app:protocol}).

\paragraph{What a guess can achieve.}
Pool chance is $b=1/|\mathcal V|$, but a model can do better without linking the queried entity to its value.
Suppose it chooses a random listed entity and returns that entity's value.
It chooses the queried entity with probability $1/K$; if it chooses another entity, the value can still match because values repeat.
Its expected recall is therefore
\begin{equation}
 g(K)=\frac{1}{K}+\frac{K-1}{K|\mathcal V|}.
 \label{eq:listed-guess}
\end{equation}
At sixteen bindings and 67 values, this guess reaches \NewGuessSixteen{} recall.
This baseline accounts for correct answers obtained by choosing a random listed entity, including matches caused by repeated values.
Recall above it does not identify the computation that produced the answer.
Supervised probes require additional controls for what their labeled training data permit them to learn \citep{hewitt2019}.

\paragraph{What the capacity statistic summarizes.}
Let $p_D(K)$ denote original-query recall and $C=p_0(1)$ the no-distractor single-binding ceiling.
We normalize recall as $r_D(K)=(p_D(K)-b)/(C-b)$ and fit a logistic curve against $\log K$ to estimate the half-recall load, $K_{50}$.
This normalization expresses recall relative to each model's single-binding performance.
It also means that $K_{50}$ is not the load at which raw recall reaches a fixed application threshold.
For distractors, $K_{50}^{D}$ retains the original ceiling $C$, so a loss at one binding contributes to the reported capacity decline.
The estimator requires a single-binding ceiling of at least 0.5, records an above-half endpoint as right-censored, and falls back to log-linear interpolation when fitting fails.
We report the curves because a scalar fit can hide a dip followed by recovery; wording and probe comparisons use raw recall throughout.

We hold the assignments fixed and change how the question is phrased.
This tests whether the same model retrieves the same associations more accurately when asked differently.
We evaluate five models on six loads, $K\in\{2,4,8,16,32,64\}$, with three seeds of 96 trials per cell.
Every condition retains the assignments and queried entity from the corresponding original-query trial.
Deleting \texttt{is} changes only the question to \texttt{The task for $e_j$:}.
At sixteen bindings, Pythia-410M improves from \NewFourTenOriginal{} to \NewFourTenColon{}, Qwen2.5-0.5B from \NewQwenSmallOriginal{} to \NewQwenSmallColon{}, and Pythia-160M from \NewOneSixtyOriginal{} to \NewOneSixtyColon{}.
All five models improve, although the improved Pythia-160M score remains below those of the other models (Table~\ref{tab:wording}).

Two further conditions test whether the gain follows from a shorter question or a closer match between the list and question.
Asking only \texttt{$e_j$ is:} removes more introductory words but retains \texttt{is}; it produces smaller gains than deleting \texttt{is} in every tested model.
Rewriting each assignment as \texttt{The task for $e_i$ is: $v_i$} matches the original question's form and also improves recall, despite lengthening the list.
Neither the shorter question retaining \texttt{is} nor the matched list reproduces the largest gain.
These variants also change token positions and continuation patterns, so they do not isolate the linguistic or circuit mechanism responsible.

\citet{jelassi2024} use phone-book entries followed by worked lookup examples, whereas the original question here supplies no demonstration.
We test both an exact-cue question, \texttt{$e_j$:}, and two answered questions about other entities in the same list.
Because values repeat, an example about another entity can display the target value.
The example condition therefore tests added demonstrations, including possible target-value repetition, rather than wording alone.
On 288 trials at sixteen bindings, Pythia-410M reaches \NewPilotFourTenExact{} with the exact cue and \NewPilotFourTenExamples{} with examples, against \NewPilotFourTenOriginal{} under the original question.
Examples do not help every model: Pythia-160M falls from \NewPilotSmallOriginal{} to \NewPilotSmallExamples{}, although its exact-cue recall reaches \NewPilotSmallExact{}.
OLMo-2-1B also loses recall under the exact cue relative to its original question.
Appendix~\ref{app:wording} gives all seven pilot models, prompt construction and readout comparisons.

We chose these variants after inspecting failures under the original question, so the comparison is exploratory.
Their different outcomes show why retrieval capacity must be measured under a specified question.

\section{Original-query recall falls with load}\label{sec:capacity}
\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{fig_p3_measured.pdf}
\caption{Recall under the original question in the corrected float32 configuration, without distractors.
The panels separate models below one billion parameters from larger models for readability.
Each curve has 576 trials per load.
The dashed grey curve is the collision-adjusted guess among listed values for a pool of 67.
These curves describe the original query; Figure~\ref{fig:wording} changes that query while retaining the associations.}
\label{fig:capacity}
\end{figure}
All \NewNModels{} models retrieve a single listed value with recall between \NewSingleLo{} and \NewSingleHi{} in the current configuration.
At one binding, copying the only value is sufficient; distinguishing associations becomes necessary when other values appear.
With two bindings, no model exceeds \NewTwoHi{} recall.
At sixteen bindings, the \NewNSmall{} models below one billion parameters range from \NewSmallSixteenLo{} to \NewSmallSixteenHi{} (Figure~\ref{fig:capacity}).
These scores describe recall under the original question; the query changes in Section~\ref{sec:wording} show that they are not intrinsic storage limits.

The fitted no-distractor capacities span \NewKLo{} to a right-censored endpoint above 64, with substantial variation across model families (Table~\ref{tab:measured}).
OLMo-2-1B has a nonmonotone curve: recall at two bindings is lower than at several larger loads.
A high fitted capacity therefore does not guarantee that every smaller load meets a reliability requirement.
Architecture, tokenizer, data and pretraining duration all vary across families, so these curves cannot isolate the cause of the differences.

\paragraph{Distractor text.}\label{sec:interference}
The added block lowers fitted capacity in many models, while OPT-1.3B improves under this summary.
Among the \NewRetainedN{} models with uncensored fitted endpoints in both conditions, the median ratio $K_{50}^{D}/K_{50}$ is \NewRetained{}.
OLMo-2-1B is omitted from that ratio because its no-distractor value is a bound.
The result combines length, content and distance; it does not estimate the effect of distractors under the improved query.
The raw recalls in Table~\ref{tab:measured} show how the fitted changes relate to performance at individual loads.

\paragraph{Which wrong values are returned.}
We classify the wrong answers in the thirteen exploratory models.
Most are values assigned to another listed entity.
At sixteen bindings without distractors, this share ranges from \NewListedErrorLo{} to \NewListedErrorHi{}, conditional on each model's errors among 576 prompts.
A uniform draw from nongold pool values would produce shares of \NewListedNullLo{} to \NewListedNullHi{} on those same error trials.
The errors therefore concentrate on alternatives supplied by the list rather than arbitrary pool values.
A probe can test whether the hidden state distinguishes the queried value from these listed alternatives.
The error counts alone cannot identify a misbinding mechanism.

\section{Hidden-state probes exceed a trained candidate-logit decoder}\label{sec:hidden}
We next ask whether a supervised classifier can recover the correct value from the hidden state under the original question.
We sample residual-stream activations at the last question token, at quarter, half, three-quarter and full depth.
A multinomial logistic regression, the hidden-state probe, learns to predict the assigned value from that vector \citep{alain2016}.
The language model stays frozen while the probe learns from labeled prompts.
Each trial is evaluated out of fold: the probe trains on other seed groups, with standardization fit only to those training groups.

Choosing the highest logit is only one way to use the output scores.
A classifier can also use the pattern of scores across all candidates to predict the answer.
We therefore train a second multinomial logistic regression on all candidate-value logits, with the same labels, folds and regularization rule as the hidden-state probe.
The candidate-logit decoder thus learns a new decision rule from the model's existing output scores.
A hidden-state probe that outperforms it recovers more correct answers than this particular score mapping.
The comparison does not establish optimal decoding of either representation or rule out a stronger nonlinear score decoder.

\paragraph{Testing on additional models.}
The first thirteen models were exploratory; we then registered the analysis for Pythia-1.4B, Pythia-2.8B and Qwen2.5-1.5B before fitting their probes.
The registration fixes three-quarter depth, sixteen bindings and no distractors, preventing selection of the layer and load from these models' probe results.
It requires a probe advantage of at least 0.10 over native output, with a positive lower confidence bound, in at least two models.
A separate criterion requires a positive lower bound over the candidate-logit decoder in at least two models.
A foil probe predicts the next listed entity's value; its registered acceptance interval checks whether the main probe's success could be matched by reading another listed value.
Two pooled native-output summaries were visible at registration, so the held-out status applies to the probe comparison rather than to every observed model statistic.

Both primary comparison criteria pass (Figure~\ref{fig:heldout}).
\NewHeldPone{} of three models meet the registered advantage over native output, and \NewHeldPtwo{} of three exceed the trained candidate-logit decoder with positive lower bounds.
Pythia-1.4B reaches \NewHeldOneFourProbe{} probe recall, compared with \NewHeldOneFourOutput{} native recall and \NewHeldOneFourLogits{} for the score decoder.
Pythia-2.8B reaches \NewHeldTwoEightProbe{}, compared with \NewHeldTwoEightOutput{} and \NewHeldTwoEightLogits{}.
Qwen2.5-1.5B reaches \NewHeldQwenProbe{}, compared with \NewHeldQwenOutput{} and \NewHeldQwenLogits{}; its positive gain over output misses the registered ten-point minimum.
All three primary foil controls meet their registered interval (Appendix~\ref{app:heldout}).

Each additional model uses its own trained classifier; transferring a trained probe between models was not tested.
A probe advantage can also occur under an improved question.
Under the exact cue, the Pythia-160M probe reaches \NewPilotSmallProbe{} recall, against \NewPilotSmallExact{} native recall and \NewPilotSmallLogits{} for its score decoder.
Even with higher native recall, the probe predicts more answers correctly.
This pattern does not hold consistently with worked examples (Appendix~\ref{app:wording}).

\section{Pretraining evidence depends on the layer tested}\label{sec:development}
Load curves change the number of associations presented to a fixed model.
To examine learning, we instead compare checkpoints from the same training run.
Probe accuracy at one layer cannot establish when bindings first become available throughout the network.
We therefore sample four depths in Pythia-160M and Pythia-410M, using the same capacity protocol at ten checkpoints from step 1{,}000 to 96{,}000.

\centering
\includegraphics[width=\linewidth]{fig_p3_checkpoint.pdf}
\caption{Exploratory checkpoint probes on the same capacity protocol at sixteen bindings.
Pythia-160M and Pythia-410M each have ten checkpoints from step 1{,}000 to 96{,}000.
Each plotted recall uses 576 out-of-fold trials.
Teal lines distinguish the four sampled layers; clay is native output.
Dashed grey is the collision-adjusted listed-value guess.
The final saved state includes the final layer normalization.
These are sampled-depth trajectories, not a registered test of an emergence threshold.}
\label{fig:checkpoint}
\end{figure}
In Pythia-410M, recall differs between the sampled layers.
Under distractors at step 96{,}000, its layer-18 probe reaches \NewCkptProbe{} recall, against \NewCkptOutput{} native recall and \NewGuessSixteen{} for the listed-value guess.
Its layer-12 probe reaches \NewCkptMiddle{} on the same condition (Figure~\ref{fig:checkpoint}).
The layer-18 probe therefore recovers more values than the middle-layer probe under the same query.
By contrast, no sampled Pythia-160M layer exceeds \NewCkptSmallMax{} across these checkpoints and conditions.
Pythia-160M nevertheless retrieves more accurately under another question (Section~\ref{sec:wording}).
Its low probe scores here apply to the tested layers and original query; they cannot establish a lack of binding information under every query.

Our earlier study compared probe predictions with model errors across Pythia checkpoints \citep{decodable2609}.
In its six-binding protocol, the share of Pythia-1.4B errors with a correct listed-value probe prediction rises from \DvPostProbeRightFirst{} to \DvPostProbeRightFinal{} across the recorded checkpoints.
The records lack prompt identifiers, so these are changing error-group shares rather than tracked changes in individual answers.
In a separate selected-layer steering experiment, intervening where probe and output disagree raises final-checkpoint accuracy from \DvStAcc{} to \DvGatedFinal{}.
The gain requires a supervised probe and a large steering vector that can impose an answer.
Changing the state can therefore change the output, but this does not establish that ordinary generation uses the probed information (Appendix~\ref{app:probes}).

Our earlier study also compared trained state and candidate-logit decoders, finding no detected final-state advantage on late-checkpoint model errors.
The present test instead compares intermediate-state decoding with candidate-logit decoding, using accuracy over all trials under the capacity protocol.
The layer, scoring population and metric differ between the studies, so the contrasting results cannot be attributed to layer choice alone.

\section{What a capacity measurement can decide}\label{sec:use}
These results suggest checking the question and readout before concluding that a retrieval task requires a larger model.
For a small model assigned a fixed task, one can first compare ways of asking for the value on matched contexts.
A candidate-logit decoder can then test whether labeled examples improve selection from the output scores, while a hidden-state probe tests prediction from an internal state.
These options have different requirements: query changes need validation examples, score decoders require logits, and hidden-state probes require activations and labeled training data.
The gains on this task give reasons to test these options; their value for an application requires evaluation on that application.

An application also needs an absolute reliability criterion.
For target recall $\pi$, the relevant measured loads are $\{K:p_D(K)\geq\pi\}$ under its selected protocol.
A fitted $K_{50}$ cannot supply that set, because it rescales by single-binding performance and smooths a curve that may be nonmonotone.
Every model here fails a 0.9 criterion at two bindings under the original question, while the wording controls establish that some failures are query-dependent.
Protocol selection should therefore precede testing on new contexts at the loads the application requires.

Retrieving several values correctly is a stricter requirement than retrieving one.
If their marginal recalls are $p_1,\ldots,p_m$, then
\begin{equation}
\max\Big\{0,1-\sum_{j=1}^{m}(1-p_j)\Big\}
\leq \Pr(\text{all }m\text{ correct})\leq\min_j p_j.
\label{eq:joint-recall}
\end{equation}
The lower bound follows because failure of the whole set requires at least one individual error; the upper bound follows because joint success requires every individual success.
No independence assumption is needed.
For example, five marginal recalls of 0.9 permit joint success as low as 0.5.
Since our trials query one entity per context, they do not measure this joint event.
Joint retrieval must therefore be tested before using these scores to predict tool-call reliability.

\section{Related work}\label{sec:related}
\paragraph{From copying to binding mechanisms.}
\citet{jelassi2024} show that pretrained transformers retrieve phone-book entries using prompts with worked examples.
Their prompts differ from our zero-shot question.
Our exact-cue and worked-example comparisons test how such format changes affect recall on the same assignments.
\citet{binding2310} identify binding IDs through causal interventions, while \citet{mixing2510} show that models combine positional, lexical and reflexive retrieval mechanisms as contexts become more complex.
Several of these mechanisms could produce our errors and query effects; our experiments do not identify which one is responsible.

\paragraph{Entity tracking and downstream relevance.}
\citet{kimschuster2023} evaluate tracking through sequences of state changes, and \citet{kim2405} find gains from code pretraining.
\citet{drozdz2026} report human-level tracking in naturalistic narratives at 410M parameters.
Tracking state changes requires operations absent from our static lists, so those scores do not measure the same retrieval problem.
RULER already varies retrieval complexity, target count and variable tracking \citep{ruler2404}.
HELMET further shows that synthetic needle scores do not reliably predict downstream performance \citep{yen2025helmet}.
Our synthetic lists let us compare questions and readouts on matched assignments.
Whether these scores predict application performance remains untested.

\paragraph{Recoverable information and its expression.}
\citet{orgad2024} and \citet{karim2026} recover correct-answer information on model errors, including synthetic key--value failures in the latter study.
\citet{lepori2026} extend the distinction to models that encode novel semantics in context but struggle to use them in downstream tasks.
Our work builds on this evidence that correct-answer information can be recovered despite an incorrect model output.
\citet{villuri2026} show that output calibration explains much of such a gap in a synthetic verification task, motivating a learned score decoder before attributing the advantage to internal access.
We extend our earlier trained-decoder comparison \citep{decodable2609} with matched query changes and a preregistered test on additional models.
The results concern the supervised decoders tested here, subject to the methodological limits of probing \citep{hewitt2019,belinkov2022}.

\paragraph{Development and intervention.}
\citet{billa2026} find task-relevant probe information before behavioral improvement in transformers, while our earlier binding study follows probe accuracy and steering across training \citep{decodable2609}.
We examine the same question under the capacity protocol, comparing probes at several depths.
Our earlier error-detection and repair study addresses actionable probes at final checkpoints \citep{legible2609}.
Those experiments use different protocols from the held-out test reported here and are not an independent replication.
Activation steering can change a model's answer \citep{li2023iti,turner2023}; establishing that ordinary generation uses the same information requires a more selective causal test.

\section{Limitations}\label{sec:limits}
The task measures static, single-token retrieval with pool-restricted scoring.
It does not evaluate natural-language coreference, state updates, generated tool calls or joint retrieval, and we do not measure whether its capacity summaries predict those tasks.
The five-model wording factorial and seven-model pilot are exploratory and use no distractors.
Their results establish sensitivity to the tested questions, not robustness across paraphrases or a linguistic cause.
Load changes length, distractors change both length and content, and the execution correction combines precision, padding and position handling.
These comparisons leave the corresponding causal effects unresolved.

The probe results depend on supervision and the choice of decoder.
Each model and condition receives separately fitted classifiers, and the candidate-logit decoder is one linear comparator rather than an optimal decoder of all output information.
Prompt bootstrap intervals condition on fitted predictions and exclude probe-refitting and training-run variation.
The held-out models come from families already represented in the exploratory set.
The wording pilots also use fewer training examples and loads than the main probes.
The checkpoint sweep samples four depths at two sizes, so failed decoding cannot establish absence from other states or readouts.
Earlier steering uses a different protocol and large vectors that can impose an answer.

\section{Conclusion}\label{sec:conclusion}
On matched prompts, changing the question recovers associations missed under the original wording.
With the original question fixed, supervised probes outperform trained candidate-logit decoders in the preregistered comparison.
These results support testing the question and readout at the required load before interpreting output failure as a reason to increase model size.
Testing a fixed retrieval protocol on new formats, joint queries and downstream tasks would establish whether these gains help choose a smaller model for an application.

\section{Experimental details}\label{app:protocol}
\paragraph{Word pools and matching.}
The entity and value pools contain common technical words filtered to single tokens when preceded by a space.
The lists overlap in three words: \texttt{commit}, \texttt{index} and \texttt{lock}.
Entities are sampled without replacement and values with replacement.
The generator selects the queried entity uniformly after drawing the assignments.
It uses the same seed formula in the original-query, wording and checkpoint measurements.
Wording comparisons retain entity IDs, value IDs and query indices within each matched trial.

\paragraph{Execution and storage.}
The main capacity grid contains \NewNPrompts{} prompt evaluations across \NewNModels{} models.
Each model has 180 cells: fifteen loads, two distractor conditions and six seeds.
The 768-token encoding limit exceeds the longest original-grid prompt; the earlier replay found no truncated questions.
Float32 refers to model execution and saved candidate logits.
The runner stores the sampled hidden states in float16 to reduce storage, then converts them to float32 for classifier fitting.

The initial continuous-protocol results used bfloat16 execution on Trainium.
The rerun uses float32 execution with TF32 disabled and dynamic padding on a CPU.
GPT-2 receives mask-derived position IDs.
The earlier model exclusions and scaling fits do not apply to these corrected inputs.
A factorial test that varies precision, padding and position handling separately remains necessary to explain the configuration difference.

\paragraph{Capacity fitting.}
We fit
$r(K)=1/(1+\exp\{\beta(\log K-\log K_{50})\})$
to recall normalized by the no-distractor single-binding ceiling.
The estimator uses the grid endpoint for its censoring rule and log-linear interpolation if nonlinear fitting fails.
Because the endpoint rule does not inspect every earlier crossing, a right-censored value does not establish threshold retention at every smaller load.
The original measured curve remains the reference for an absolute threshold.
Table~\ref{tab:measured} gives the fitted capacities.

\paragraph{Reproducing the experiments.}
The repository's \texttt{analysis/gpu\_capacity\_dev.py} evaluates models, \texttt{analysis/p3\_probe\_capacity.py} fits probes and candidate-logit decoders, and \texttt{analysis/p3\_paired\_ci.py} computes paired confidence intervals.
Results are in \texttt{results/measurement/}, with per-trial assignments and predictions in its \texttt{predictions/} subdirectory.
Running \texttt{make} builds the figures, tables and paper from these results.
Hidden activations are not distributed; fitting probes requires rerunning model evaluation.

\section{Held-out probe test and controls}\label{app:heldout}
\paragraph{Selection and chronology.}
The first thirteen models formed an exploratory set.
The remaining three were still being processed when the registration was frozen on 24 October 2026 at 17:27 UTC.
Two pooled native-output summaries were already visible, as the registration states.
No hidden-state probe had been fit on these three models at that time.
Thus ``held-out'' describes the model-level analysis test, not previously unseen model families or unseen native-output behavior.

\paragraph{Probe fitting.}
For each model and condition, a standardized multinomial logistic regression uses inverse regularization strength 0.5 and up to 1{,}000 iterations.
It trains on all measured loads in the training seeds and holds out seed groups $\{0,1\}$, $\{2,3\}$ and $\{4,5\}$ in turn.
Scaling uses only training-fold statistics.
The candidate-logit decoder uses the same procedure on the vector of all pool logits.
The registered layer is the third saved depth, $\lfloor3L/4\rfloor$.
The registered load is sixteen bindings.
The primary condition is no distractor; the distractor condition is reported as secondary.
The main comparison scores top predictions over the full pool, not predictions restricted to the listed values.

\paragraph{Registered criteria.}
P1 requires probe recall minus native-output recall of at least 0.10, with a positive lower 95\% bound, in at least two of three models.
P2 requires a positive lower 95\% bound for probe recall minus candidate-logit-decoder recall in at least two models.
P3 requires the foil probe's listed-value recall to lie within $[0.03,0.13]$ in all three primary-condition models.
The foil target is the next listed entity's value, not the queried entity's value.
The preregistration requires both P1 and P2.
If P3 fails, the probe cannot be interpreted as reading the queried binding in the affected model.
The observed primary-condition counts are \NewHeldPone{} of three for P1 and \NewHeldPtwo{} of three for P2; all three satisfy P3.
Foil recall across the primary and secondary conditions ranges from \NewFoilLo{} to \NewFoilHi{}.
Passing the foil interval is not a test of equivalence to chance.

The probe runner also supports shuffled training labels, prediction of the queried entity, and a pre-question state control.

\section{Exact-cue and worked-example pilot}\label{app:wording}
The exploratory pilot covers seven models at loads $\{1,2,4,8,16,32,64\}$, with three seeds of 96 trials per cell.
Each alternative condition reuses the original condition's assignments, queried entity, gold value and trial identifiers.
The exact-cue question is \texttt{$e_j$:}, which repeats the local form of a declaration.
The worked-example condition appends answered questions of the form \texttt{The task for $e_i$ is: $v_i$}, then asks the original question about $e_j$.
Example entities are sampled without replacement from the other listed entities, excluding $e_j$.
At one binding there is no example; at two bindings there is one.
Values repeat, so an example's answer can equal the target value even though the entity differs.
This is additional supervision from the same context, rather than a change in wording alone.

\section{What recall alone leaves unidentified}\label{app:identity}
A low output score does not identify the stage of failure.
For illustration, suppose the queried association is available with probability $s$, a readout succeeds given availability with probability $a$, and either failure produces a uniform pool guess.
Under these assumptions,
\begin{equation}
p=b+(1-b)sa.
\label{eq:storage-access}
\end{equation}
For $u=(p-b)/(1-b)$, both $(s,a)=(u,1)$ and $(s,a)=(1,u)$ produce the same recall.
The same recall is therefore compatible with different probabilities of availability and successful readout.
This illustration does not establish that a language model has two such stages or that probe accuracy estimates $s$.
The query and probe experiments add observations, but they do not estimate these latent probabilities.

The distractor normalizations also answer different questions.
Let $C_0=p_0(1)$, $C_D=p_D(1)$ and $g_D=(C_D-b)/(C_0-b)$.
For $C_D>b$,
\begin{equation}
\frac{p_D(K)-b}{C_0-b}=g_D\frac{p_D(K)-b}{C_D-b}.
\label{eq:ceiling-decomposition}
\end{equation}
Normalizing by the distractor condition's own ceiling removes its single-binding decline.
The capacities in Table~\ref{tab:measured} retain that decline by using $C_0$ for both conditions.
This identity alone does not establish that distractors preserve or change the curve's shape.

\paragraph{Middle-layer probes.}
Each checkpoint has \DvLadderTrials{} trials, split into \DvLadderTrain{} training trials and \DvLadderTest{} test trials.
A standardized multinomial logistic regression reads layer $\lfloor L/2\rfloor$ at the last question token.
Its regularization is selected by three-fold cross-validation over $\{0.01,0.03,0.1,0.3,1,3,10\}$.
The middle-layer probes in Pythia-160M and 410M remain at or below \DvSmallMax{} across \DvSmallCkptAll{} checkpoints.
The larger models' final scores range from \DvBigFinalLo{} to \DvBigFinalHi{}.
The higher recall at a later layer in Figure~\ref{fig:checkpoint} shows why low middle-layer scores cannot describe the whole network.
Repeated embedding hashes identify repeated downloads; the earlier Pythia-2.8B ladder retains only \DvTwoEightKept{} distinct checkpoint records and is excluded from that ladder.
This exclusion does not apply to the current final-checkpoint Pythia-2.8B measurement.

\paragraph{Layer selection and steering.}
Pythia-1.4B has \DvStTrials{} trials per checkpoint, divided into thirds for probe training, layer selection and testing.
At every layer, the probe uses inverse regularization strength 0.5.
Selection chooses the probe most accurate on wrong outputs in the second third.
The model's answer and the value used for steering are restricted to the six listed values.
On the final test third, the chosen layer is \DvStLayer{} of \DvStFinalLayer{}, and the probe's pool prediction is correct on \DvStProbeWrong{} of \DvStWrong{} wrong answers (95\% interval \DvStProbeWrongLo{} to \DvStProbeWrongHi{}).
The final-layer probe reaches \DvStProbeWrongFinal{} on the same wrong answers.
The differing scores do not establish loss of the binding between those layers.

The intervention adds a unit vector scaled to half the mean hidden-state norm at the selected site.
It is applied to the output of the block after the layer whose state supplies the probe.
The direction is either the difference of target and emitted-value probe weights, mapped back to raw coordinates, or the difference of target and emitted-value mean states.
A fresh random direction of equal norm is the control.
Gold-target steering requires the answer label; probe-target steering uses a separately supervised classifier's prediction.
At the final Pythia-1.4B checkpoint, mean-difference steering where probe and output disagree raises accuracy from \DvStAcc{} to \DvGatedFinal{}.
At the final Pythia-6.9B checkpoint, it raises accuracy from \DvSixGatedBase{} to \DvSixGatedFinal{}.
These large interventions can impose a candidate answer, so they show controllability rather than ordinary causal use of the probed information.
